⏱️ Stopwatch Web Application

A modern and responsive Stopwatch Web Application built using HTML, CSS, and JavaScript. This project provides precise time tracking with support for Start, Pause, Reset, and Lap functionalities. The application features a sleek dark-themed interface with neon-inspired styling, delivering both functionality and an appealing user experience.

🚀 Features

- ▶️ Start the stopwatch
- ⏸️ Pause and resume the timer
- 🔄 Reset the stopwatch and lap records
- 🏁 Record unlimited lap times
- ⚡ Real-time tracking with millisecond precision
- 🎨 Modern dark-themed UI with neon effects
- 📱 Responsive and user-friendly design
- 📋 Scrollable lap history section

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

🎯 How It Works

1. Click Start to begin tracking time.
2. Click Pause to temporarily stop the timer.
3. Click Lap to save the current elapsed time.
4. Click Reset to clear the timer and all recorded laps.
